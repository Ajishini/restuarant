A restaurant website developed using HTML5 and CSS3 to practice frontend development and web design.

## 📌 Project Overview

This project demonstrates the use of HTML to structure website content and CSS to create an attractive layout and styling.

- Clean and organized website layout

## 🚀 How to Run the Project

1. Clone the repository:

   ```bash
   git clone https://github.com/Ajishini/restuarant.git
   ```
